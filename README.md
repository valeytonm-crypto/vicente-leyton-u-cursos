# Vicente Leyton — maqueta de cursos

Proyecto de **diseño estático no oficial** inspirado en el estilo de plataformas universitarias de cursos. **No replica registros académicos ni acredita matrícula.**

## Ver localmente

Abre `index.html` en tu navegador. No requiere instalar paquetes.

## Cambiar asignaturas

Edita el arreglo `cursos` al principio de `script.js`. Cada objeto tiene `codigo`, `nombre`, `seccion`, `periodo` e `icono`. Los cursos actuales son solo ejemplos, porque el enlace de referencia no pudo consultarse.

## Publicar en GitHub Pages

1. En GitHub crea un repositorio nuevo, por ejemplo `vicente-leyton-cursos`.
2. Sube `index.html`, `styles.css` y `script.js` a la raíz.
3. En **Settings → Pages → Build and deployment**, elige **Deploy from a branch**, rama **main** y carpeta **/(root)**, y guarda.
4. GitHub mostrará la URL de tu sitio en esa sección.

> **Aviso:** maqueta independiente, sin relación con U-Cursos o la Universidad de Chile.
